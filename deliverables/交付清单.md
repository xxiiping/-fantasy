## 三、如何重新导出（模板已安装，一条命令）

前置：Godot 官方 export templates 已安装在
`~/Library/Application Support/Godot/export_templates/4.7.1.stable/`（macos.zip 已就位）

**现在只需要：**

```bash
./tools/export.sh
```

脚本会自动摘掉 MCP 的 autoload、导出、再还原 `project.godot`。
以下是它内部做的事，供参考：

```bash
# 1) 先摘掉 MCP 插件的 autoload，否则导出包启动会报"autoload 脚本不存在"
#    用 MCP 工具 autoload_manage(remove, "_mcp_game_helper")

# 2) 导出
/Applications/Godot.app/Contents/MacOS/Godot \
  --headless --path . \
  --export-release "macOS" build/macos/ZhengHeFantasy.zip

# 3) 导完把 autoload 加回去
```

`export_presets.cfg` 已配好，其中：
- 排除 `docs/ tools/ tests/ addons/ .downloads/` —— 证据与开发工具不进包
- `import_etc2_astc = true` 已在项目设置里打开（否则 universal 架构导不出来）

### macOS 包第一次打开可能被 Gatekeeper 拦

包未签名。对方如果打不开，让他们在 App 上**右键 → 打开**，或跑：

```bash
xattr -dr com.apple.quarantine ZhengHeFantasy.app
```
