## 零、全局规范

### 0.1 画面

| 项 | 规格 |
| --- | --- |
| 分辨率 | 1920×1080（当前 Demo 为 1280×720，完整版提升） |
| 风格 | 水墨：宣纸底、墨色晕染、留白 |
| 镜头 | 以固定机位为主；推镜只用在章节开场与结局；**不做自由运镜** |

**色板**

| 名 | 值 | 用途 |
| --- | --- | --- |
| 墨 | `#1a1a1e` | 剪影、正文 |
| 宣 | `#e8e2d5` | 纸底、对话框 |
| 赭 | `#a8603c` | 灯火、暖光 |
| 石青 | `#4a6b7c` | 海、雾的冷部 |
| 朱砂 | `#b23a2e` | 判错、危险、印章 |

**转场**

| 类型 | 表现 | 时长 |
| --- | --- | --- |
| 墨滴化开 | 一滴墨从画面中心晕开，盖住上一场 | 0.6s |
| 海图推镜 | 见 0.4 | 2.5s |
| 章节标题 | 海图定格 → 标题墨迹浮现 | 1.5s |

### 0.2 UI

| 元素 | 规格 |
| --- | --- |
| 对话框 | 底部，宣纸底 78% 不透明，墨色细边，横排，字号 22 |
| 剪影立绘 | 对话框上方左/右两侧，墨色剪影，出现时自下淡入 0.3s |
| 交互提示 | 画面上的墨点，悬停时晕开一圈 |
| 资源栏 | 右上角极小字：`淡水 6` `灯油 2`，无图标 |
| 记录 | 「海图」按钮，**随时可开**，查看已解开的次序与线索；毕业考也允许开着查 |
| 章节选择 | 通关后解锁。标题画面进入，可跳到任意已解锁章节（方便试玩与评审） |

> **不用数字进度条、不做血条。** 所有状态用文字与画面表达。

### 0.3 音频

| 曲目 | 用途 |
| --- | --- |
| 《雾》 | 标题 / 章节内通用底噪 |
| 《行》 | 航行与海图推镜 |
| 《账》 | 结局 |

音效：墨点点击、符文亮、机关暗、雾涌、灯燃、水声、回声低语（可叠加）

### 0.4 章节开场：海图推镜

**统一流程（2.5 秒 + 1.5 秒）**

1. 全屏手绘海图（宣纸底，墨线勾出的海岸与航线）
2. 镜头从上一处标记**推近**到本章目标点，航线用一条墨线延伸过去
3. 推到位，画面暗一下
4. 标题以毛笔字浮现：`第二章 · 残骸`
5. 下方一行小字引文

### 0.5 双主角能力表

| | **郑和**（活人的手） | **阿沅**（回声的眼睛） |
| --- | --- | --- |
| 符文机关 | ✔ 可操作 | ✘ 看不懂字，点了没反应 |
| 修缮 / 打捞 / 转帆 | ✔ | ✘ |
| 看见回声 | 只能看到**模糊的人影** | ✔ 能**听清**他们说什么 |
| 穿过回声 | 会被他们"让开" | ✔ 回声**穿不过她**（她也是回声） |
| 读潮 | 需要仪器（牵星盘 / 潮表） | ✔ **不需要**任何仪器 |
| 界面特征 | 有刻度、有文字、有目标值 | **无刻度、无数字**，只有墨色涟漪 |

> 阿沅的所有交互界面都是"没有字的"。这是她和郑和最本质的区别。
